## Explicit non-goals for M01

- No PostgreSQL, Authentik, NATS, Centrifugo, object storage, tenancy schema or production deployment changes.
- No conversion of every direct clock/randomness/filesystem call in one pass; introduce ports at established seams with actual use cases.
- No endpoint, wire payload, database migration, permission bit, session or stored-data changes.
- No hollow `CommunityContext` and no mapping Quarel's ServerID/member ID to future global IDs.
- No Docker daemon dependency from inside application containers and no `podman` compatibility claim based only on Docker Compose parsing.

## First independent plan review — dispositions

1. **M00 baseline blockers vs M01 gate:** accepted and strengthened. M01 remained blocked until M00's required baseline checks completed; completion evidence is recorded in `docs/baseline/results.md`. No gate waiver was used.
2. **Import boundaries over current Quarel graph:** accepted. Add `internal/realtime`, `internal/voice`, `internal/backup`, `internal/sqlitedb`, `internal/secret`, and deploy manifests to P1; handlers are methods in service packages. Use an explicit legacy allowlist and negative test.
3. **CommunityContext data semantics:** accepted. Do not alias Quarel ServerID/member ID to future IDs. Defer the type and propagation until trustworthy global IDs and trace context have providers; no hollow type.
4. **Ports semantics:** accepted. Preserve `Server.now`; restrict ID generation to audited ordinary-ID call sites and exclude the admin setup authentication code; separate ephemeral `RealtimeSink` from durable outbox `EventPublisher`; defer `ObjectStore` to M10 and record local filesystem guarantees.
5. **Podman verification and process boundary:** accepted. Keep temporary LiveKit-in-server exception until M08. Expand container scope to site, MCP, infra and Docker test path; Electron is built/tested in Docker and distributed natively. Pin Podman version/provider and run real Podman deployment before M17/M19; Docker parsing is insufficient. Explicitly test current host-network/UPnP, privileged 443, UDP/media and source-IP constraints; no Podman host currently exists.
6. **ADR-002 scope:** accepted. Limit it to boundaries/failure domains/placement and defer transactional/outbox details to M03/M05.
